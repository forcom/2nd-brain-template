# ISO 품질경영 표준군

ISO 9000 계열은 공통 어휘에서 시작해 요구사항, 적용 지침, 지속적 성공과 프로젝트 품질로 역할을 나눈다. 한 문서가 다른 문서를 대체하는 계층이 아니라 목적에 따라 조합하는 도구상자에 가깝다.

| 문서 | 이 배치의 판 | 주된 역할 |
| --- | --- | --- |
| KS Q ISO 9000 | 2015 | 품질경영시스템의 기본사항과 용어를 제공한다. ^[raw/papers/ks-q-iso-9000-20210330-ko.md] |
| KS Q ISO 9001 | 2015 | 조직의 품질경영시스템 요구사항을 규정한다. ^[raw/papers/ks-q-iso-9001-20241213-ko.md] |
| KS Q ISO/TS 9002 | 2016 | ISO 9001:2015 요구사항을 적용하기 위한 지침을 제공한다. ^[raw/papers/ks-q-iso-ts-9002-20231017-ko.md] |
| KS Q ISO 9004 | 2018 | 품질경영을 조직의 지속적 성공과 자기평가 관점으로 확장한다. ^[raw/papers/ks-q-iso-9004-20220630-ko.md] |
| KS Q ISO 10006 | 2017 | 프로젝트 환경에서 품질경영 원칙과 실무 지침을 적용한다. ^[raw/papers/ks-q-iso-10006-20241213-ko.md] |

## 사용 순서

1. ISO 9000으로 용어와 품질경영 원칙을 맞춘다.
2. ISO 9001로 조직이 충족할 요구사항과 프로세스 경계를 정한다.
3. ISO/TS 9002를 구현 해석의 보조자료로 사용한다.
4. ISO 9004로 적합성 확인을 넘어 조직의 성숙도와 지속적 성공을 점검한다.
5. 프로젝트 중심 업무에는 ISO 10006의 맥락별 지침을 연결한다.

요구사항 문서와 지침 문서를 구분하면 “어떻게 할 것인가”라는 예시를 필수 조항으로 오인하거나, 반대로 요구사항을 선택적 권고로 낮추는 오류를 줄일 수 있다.

## 인접 표준

품질경영의 공통 구조는 의료기기 규제 목적의 ISO 13485, 식품안전의 ISO 22000과 화장품 GMP의 ISO 22716에서 분야별로 구체화된다. 이 경계는 [[iso-health-product-and-food-standards]]에서 비교한다. 시스템·소프트웨어 품질 모델은 조직 경영시스템과 분석 단위가 다르므로 [[iso-software-quality-and-testing-standards]]에서 별도로 다룬다.

전체 경영 구조는 [[iso-management-system-standards]], 수집된 판본과 역할의 일람은 [[iso-standards-portfolio-map]]을 참고한다.
